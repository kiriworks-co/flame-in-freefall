# Pasta de recursos originais NASA

Nenhum PDF, CSV ou planilha experimental foi baixado nesta sessão, pois o ambiente de criação do kit não conseguiu efetuar downloads externos de arquivos. **Não há dados científicos fabricados aqui.**

Utilize `python scripts/fetch_nasa_resources.py --guide` para obter o PDF NASA e `python scripts/fetch_psi_tables.py --ids PSI-25 PSI-26 PSI-68 PSI-69 PSI-98 PSI-99 PSI-100 PSI-101 PSI-102` para tentar baixar tabelas experimentais diretamente do PSI. Esses scripts precisam de acesso à internet; a API PSI pode mudar. Se falhar, use a interface pública NASA e importe os CSVs manualmente, preservando arquivo original, DOI, ID da investigação e URL.

Arquivos de fontes secundárias são contexto, nunca medições NASA.
